# MyPCBottleneck – Free PC Bottleneck Calculator

Open resource hub for [MyPCBottleneck.com](https://www.mypcbottleneck.com/),
a free PC bottleneck calculator for modern gaming analysis.

It helps gamers and PC builders detect CPU and GPU limits using real-world
scenarios with Ray Tracing and DLSS, simulating high-FPS 1080p and
high-fidelity 1440p/4K gaming for accurate upgrade decisions.
